Put it on GitHub

No coding needed. Dumb-A-Thon is about using AI well, not coding well.

📦 You submit three links

  • 🐙
    GitHub repo linkYour project's files, set to Public.
  • 🧪
    Prototype linkA hosted website, or any other kind of prototype. Hosting is not required.
  • 🖥️
    Slides linkA link only. Slide files are not accepted.

Due Monday 7 December, 23:59 (Malaysia time).

🤖 First, get AI to build it

Making a website? Copy this into your AI tool and fill in the brackets.

Build a simple one-page website prototype for my campus startup.
Name: [your startup name]
Problem: [the pain point]
Idea: [what it does]
Make it funny but easy to use, and make it work on phones.
Put all the HTML, CSS and JavaScript in ONE file called index.html.
Then tell me, step by step, how to test it.

🐙 Then put it on GitHub

1

Make a free account

Go to github.com and sign up. One account per team is enough.

2

Create a repository (your project folder)

  1. Click + at the top right, then New repository.
  2. Type a name, like gilbert-remote.
  3. Set visibility to Public.
  4. Turn Add README on.
  5. Click Create repository.
3

Upload your files

  1. On your repository page, click Add file, then Upload files.
  2. Drag your files into the box.
  3. Click Commit changes (it may say Propose changes).

Website? The main file must be named index.html and must not be inside a folder.

4

Switch on free hosting (websites only)

  1. In your repository, click Settings.
  2. In the left menu, click Pages.
  3. Under Build and deployment, set Source to Deploy from a branch.
  4. Set the branch to main and the folder to / (root).
  5. Click Save.
5

Copy your links

Wait a few minutes (it can take up to 10), refresh the Pages screen and click Visit site.

  • Prototype link: https://your-username.github.io/your-repo-name/
  • Repo link: https://github.com/your-username/your-repo-name

🔧 Not a website? That's fine

Any kind of prototype counts. Share a link to it, for example:

  • A Figma or Canva mock-up that anyone with the link can view.
  • A video of your physical build (YouTube set to Unlisted, or Google Drive with link sharing on).
  • A simulation or CAD model share link, such as Tinkercad or Wokwi.

You still need a GitHub repo: upload photos, sketches or project files, and describe your prototype in the README.

🖥️ Your slides link

  • Google Slides: Share, set General access to Anyone with the link as Viewer, then Copy link.
  • Canva: Share, allow anyone with the link to view, then copy the link.

Links only. Do not send a PowerPoint or PDF file.

✅ Before you submit

  • Open all 3 links in a private / incognito window. If they open there, the judges can open them.
  • Never put passwords or API keys in your files. A public repo is visible to everyone.

🆘 Something broke?

My website shows "404"

Check that the file is called index.html (all lowercase), is not inside a folder, and that Pages is saved with the main branch. Then wait 10 minutes.

I changed a file but the site looks the same

Upload the new file again, wait a few minutes, then hard-refresh with Ctrl+Shift+R (Cmd+Shift+R on a Mac).

I have no idea what is happening

Take a screenshot or copy the error message, paste it into your AI tool and ask it to explain the fix step by step.
